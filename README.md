# Saathi – Perfect Roommate Finder

Saathi is a MERN-stack web application designed to help students find compatible roommates based on their preferences, lifestyle, and requirements.

## Features

* 🔐 User registration and login
* 👤 User profiles
* 🏠 Roommate discovery
* 🔎 Search and filtering
* 🤝 Find compatible roommates
* 📱 Responsive and user-friendly interface
* 🔒 Secure authentication

## Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT
* **Styling:** CSS

## Project Goal

Saathi makes finding the right roommate easier by connecting students with people who have similar preferences and lifestyles.

**Saathi — Find your perfect roommate.**
